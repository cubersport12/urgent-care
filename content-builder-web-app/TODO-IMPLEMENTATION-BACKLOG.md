# План реализации функционала и реестр заглушек (Backlog)

Данный документ содержит полный перечень компонентов, диалогов и методов в веб-приложении **`content-builder-web-app`** (файловый менеджер и смежные модули панели управления), в которых в настоящий момент установлены заглушки, моковые данные или которые требуют доработки логики взаимодействия с бэкендом.

---

## 1. Файловый менеджер (`FoldersExplorerComponent`)

### 1.1 Перемещение элементов между папками (Drag & Drop)
- **Файл:** `src/app/core/components/folders-explorer/folders-explorer.component.ts`
- **Текущее состояние:** Визуальная поддержка Drag & Drop (CDK Drop List / HTML5 Drag) реализована для левой и правой панели.
- **Что требуется реализовать:**
  - При перетаскивании элемента (статья, тест, спасение, папка) на другую папку или между панелями отправлять мутацию в API:
    - Для папок: `AppFoldersStorageService.updateFolder(folderId, { parentId: targetFolderId })`
    - Для документов (статей): `AppArticlesStorageService.updateArticle(articleId, { parentId: targetFolderId })`
    - Для тестов: `TestsActions.UpdateTest(testId, { ...test, parentId: targetFolderId })`
    - Для спасений: `RescueActions.UpdateRescueItem(rescueId, { ...rescue, parentId: targetFolderId })`
  - После завершения запроса вызывать перезагрузку данных обеих панелей (`_loadPanelFolder`).

### 1.2 Пакетные операции (Multi-selection Batch Actions)
- **Файлы:**
  - `src/app/core/components/folders-explorer/folders-explorer.component.ts`
  - `src/app/core/components/folders-explorer/folders-explorer.component.html`
- **Текущее состояние:** Пользователь может выделять несколько строк с зажатой клавишей `Ctrl` или `Shift` (сохраняется в сигнале `_selectedItemIds`), однако тулбар выполняет операции («Копировать», «Вырезать», «Удалить», «Назначить тариф») только над одним текущим элементом (`_singleSelectedItem()`).
- **Что требуется реализовать:**
  - Добавить методы группового копирования/вырезания: сохранять в буфер обмена массив `OptionType[]`.
  - Массовое удаление: диалог подтверждения `ConfirmDeleteDialogComponent` должен принимать массив элементов, а при подтверждении отправлять параллельные запросы на удаление через `forkJoin`.
  - Массовое назначение тарифа: вызывать `_setItemTariff` для пакета выбранных элементов.

### 1.3 Встроенный просмотр документов PDF (Inline Document Viewer)
- **Файлы:**
  - `src/app/core/components/article-editor/article-editor.component.ts`
  - `src/app/core/components/article-editor/article-editor.component.html`
- **Текущее состояние:** Метод `_openPdfContentInWindow()` открывает сгенерированный blob-URL в новой вкладке браузера `window.open(url, '_blank')`.
- **Что требуется реализовать:**
  - Создать встроенный модальный просмотрщик PDF (на базе `pdf.js` или `iframe` с `AppDialogWrapperComponent`) для предварительного просмотра документов прямо в интерфейсе администратора без открытия новых вкладок.

### 1.4 Тестовая рассылка уведомлений (`_sendTestNotification`)
- **Файл:** `src/app/core/components/folders-explorer/folders-explorer.component.ts`
- **Текущее состояние:** Метод вызывает базовый `notificationsBroadcastNotification` с тестовым заголовком и текстом.
- **Что требуется реализовать:**
  - Создать полноценный диалог выбора аудитории (все пользователи, пользователи с тарифом X, конкретный пользователь) и типа перехода при клике (открытие статьи/теста по `id`).

## 2. ИИ-генераторы контента

### 2.1 ИИ-генератор интерактивных тестов
- **Файл:** `src/app/core/components/test-editor/test-ai-generate-dialog.component.ts`
- **Текущее состояние:** Диалог полностью сверстан на `AppDialogWrapperComponent`, форма собирает тему, целевую аудиторию, сложность, количество вопросов и формат вариантов ответа. Генерация симулируется локальным `setTimeout(..., 1800)` с генерацией моковой структуры вопросов.
- **Что требуется реализовать:**
  - Подключить реальный бэкенд эндпоинт (Gemini API через бэкенд `AppAiService.generateTestQuestions(payload)`).
  - Реализовать обработку ошибок валидации JSON схемы, если модель вернет некорректный ответ, с возможностью автоматического повтора (retry).

### 2.2 ИИ-генератор клинического режима спасения
- **Файл:** `src/app/core/components/rescue-editor/rescue-ai-generate-dialog/rescue-ai-generate-dialog.component.ts`
- **Текущее состояние:** Диалог содержит форму параметров клинического случая (диагноз, возраст пациента, тяжесть, параметры таймера, целевое действие). Ответ симулируется через локальный таймер и мок-дерево сцен.
- **Что требуется реализовать:**
  - Подключить бэкенд метод генерации многошагового сценария первой помощи (`AppAiService.generateRescueScenario(payload)`).
  - Сгенерированные параметры таймера (`RescueTimerParameterVm`) и варианты действий (`RescueSceneChoiceVm`) должны валидироваться на непротиворечивость дельт значений.

## 3. Редактор спасения (`RescueEditorComponent`)

### 3.1 Валидация графа сцен и условий завершения
- **Файлы:**
  - `src/app/core/components/rescue-editor/rescue-editor.component.ts`
  - `src/app/core/components/rescue-editor/rescue-completion-dialog/rescue-completion-dialog.component.ts`
- **Текущее состояние:** Пользователь может создавать сцены и настраивать условия завершения через `RescueCompletionDialogComponent`.
- **Что требуется реализовать:**
  - Добавить клиентскую и серверную валидацию графа сцен перед сохранением:
    1. Проверка на недостижимые сцены («висячие» вершины графа).
    2. Проверка вариантов выбора с несуществующим `nextSceneId`.
    3. Проверка наличия хотя бы одного терминального исхода (успех или неуспех) из каждого возможного пути.

### 3.2 Предпросмотр миниатюр фоновых изображений
- **Файлы:**
  - `src/app/core/components/rescue-editor/rescue-editor.component.html`
  - `src/app/core/components/rescue-editor/rescue-scene-dialog/rescue-scene-dialog.component.html`
- **Текущее состояние:** При выборе фона сцены или общего фона сохраняется ID или имя файла. В таблице сцен отображается только текстовый маркер.
- **Что требуется реализовать:**
  - Загружать и отображать превью миниатюру изображения (`<img>`) через `AppFilesStorageService.getFileUrl(backgroundId)`.

- **Что требуется реализовать:**

### 5.3 Сброс пароля и отправка ссылки для входа
