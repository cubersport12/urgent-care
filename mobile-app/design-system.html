Глассморфизм, свечение, градиенты и тени — фирменные приёмы системы.

Glass — живой блюр

GlassCard · native dark
BlurView intensity 20 · фон rgba(255,255,255,0.05) · рамка 10% · блик сверху
В приложении блюр рендерится только в тёмной теме на нативе (showBlur = !isLight && OS !== 'web'). Светлая тема и web получают плоскую поверхность: светлая — #FFFFFF без тени, тёмная — полупрозрачный фон + тень glass.

Правила движения

Mount-анимациитолько entering={FadeIn…} из Reanimated. Ручной useSharedValue(0)+withTiming на web залипает на opacity 0 (баг, уже ловили)
Стаггер списковstaggerEnter(index) = FadeInDown · delay i·60 · 600 ms · springify(18/120) — единый хелпер
Pressscale 0.98 + opacity 0.85–0.95, мгновенно (Pressable state, без длительности)
Disabledopacity 0.6 (ThemeValues.disabledOpacity)
Easing входовэкспортирован enterEasing = [0.19, 1, 0.22, 1] (easeOutExpo) — им же анимируются CSS-демо выше
08

Иконки

Кроссплатформенный IconSymbol: на iOS — нативные SF Symbols (weight regular), на Android/web — MaterialIcons по таблице соответствия. Неизвестное имя рендерит null + console.warn. В коде пишется SF-имя, маппинг — деталь реализации.

09

Платформенные особенности

Темаlight / dark / system; выбор в AsyncStorage @app/theme-preference; навигация — React Navigation DarkTheme/DefaultTheme с токенами палитры; сплэш ждёт загрузки шрифтов
Блюрэкспо BlurView — только тёмная тема на нативе; web и light — плоская подложка (см. Glass)
ТениRN shadow (iOS) + elevation (Android); web переводится в box-shadow Xpx Ypx Bpx rgba(...)
ТактильностьHaptics Light impact по нажатию табов — только iOS (HapticTab)
Шрифтынатива — Expo Google Fonts (Inter, IBM Plex Mono); web — CSS-стеки с системными фолбэками
ИконкиiOS — SF Symbols; Android/web — MaterialIcons; в таблице иконок — 50 соответствий
Типографикакнопки и многострочные тексты требуют явного text-align: center (Button в RN не центрирует сам)
Известные ловушки проекта: hand-rolled fade на web залипает (см. Правила движения); GlassCard на web без блюра выглядит иначе, чем на нативе — проверять обе платформы.
