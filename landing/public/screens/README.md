# Скриншоты для лендинга

Положите сюда скриншоты из мобильного приложения **парой** — для светлой и
тёмной темы (суффиксы `-light` / `-dark`). Лендинг подхватывает их автоматически
по именам; отсутствующий файл заменяется заглушкой.

| Пара файлов                              | Экран                                          | Где в лендинге          |
| ---------------------------------------- | ---------------------------------------------- | ----------------------- |
| `home-light.png` / `home-dark.png`       | «Обучение» — список папок с материалами        | Hero                    |
| `rescue-light.png` / `rescue-dark.png`   | «Режим спасения» — сцена с выбором действия    | Секция «Режим спасения» |
| `rescue-result-light.png` / `…-dark.png` | «Режим спасения» — экран завершения с разбором | Секция «Режим спасения» |
| `stats-light.png` / `stats-dark.png`     | «Статистика» — прогресс и достижения           | «Как проходит обучение» |

Рекомендация: 1080×2340 (Android) или 1170×2532 (iPhone), без рамок — рамку
телефона рисует лендинг. Верх скриншота виден целиком, низ может обрезаться.
